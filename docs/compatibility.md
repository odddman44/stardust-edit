# 호환성과 검증 범위

## 초기 대상

- React·React DOM 19.x, Next.js 16.x App Router.
- ESM과 CSS를 처리하는 번들러. React·React DOM은 소비 앱과 공유합니다.
- 개발·배포물 검증 기준: Node 22.13.1, pnpm 11.22.0, TypeScript 5.9.3.
- Tiptap 공개 패키지 3.32.0을 사용합니다. 상용 확장·계정 가입은 필요하지 않습니다.

다른 프레임워크용 편집 UI, CommonJS 진입점, 구형 브라우저 호환 계층은 제공하지 않습니다. 컨테이너 쿼리 등 최신 CSS를 지원하는 브라우저를 대상으로 합니다.

## 검증 방법

문서 왕복·버전/구조/URL 검증, 서버 HTML·Markdown, React StrictMode, 업로드 실패·삭제·재시도·문서 전환·실행 취소, 2열 이동·해제를 자동 테스트합니다.

Playwright의 Chromium·Firefox·WebKit에서 작성·저장·복원·키보드·붙여넣기·모바일 폭을 검사합니다. 합성 클립보드·조합 이벤트는 에디터의 이벤트 처리를 검증하며 실제 운영체제 IME나 클립보드와 동일한 검증이 아닙니다.

실제 macOS 한글 IME, 실제 Safari·Edge, iOS Safari·Android Chrome 실기기 검증은 아직 수행하지 않았습니다. WebKit 실행이나 390px 화면 검사를 실기기 검증 완료로 표시하지 않습니다.

실제 운영체제 클립보드와 터치·드래그 조작도 수동 검증 전입니다. 자동 테스트의 합성 붙여넣기·드롭 결과와 구분합니다.

## 저장·변환 제한

JSON이 원본입니다. 지원하지 않는 블록·속성·미래 버전은 오류로 처리하며 자동으로 삭제하지 않습니다. 외부 문서 붙여넣기는 지원 텍스트·서식 위주이며 노션·Google Docs와 완전한 왕복 변환을 약속하지 않습니다.

데모의 저장은 브라우저 로컬 저장이며 사진은 샘플 자산으로 대체합니다. 실제 파일 저장소·인증·자산 삭제 정책은 소비 앱에서 연결하세요.
