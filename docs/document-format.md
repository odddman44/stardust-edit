# 문서 형식

원본은 `{ version: 1, content: TiptapJSON }` 객체입니다. 글의 소유자·공개 권한·작성 시각은 소비 앱에서 별도로 저장합니다. 문서 저장 전 `parseDocument`로 확인할 수 있습니다. 지원하지 않는 버전·블록·속성을 조용히 삭제하지 않고 오류로 반환합니다.

## 이미지와 저장 시점

문서에는 영구 이미지 URL·대체 텍스트·캡션을 저장합니다. 임시 업로드 노드, File 객체, blob URL은 변경 콜백의 문서에 포함하지 않습니다. 콜백의 대기·실패 수를 확인하여 저장 상태를 표시하세요. `getDocument()`는 대기·실패 항목이 남아 있으면 `UPLOAD_INCOMPLETE`를 반환합니다.

이미지를 제거해도 저장소의 파일은 자동 삭제하지 않습니다. 문서 간 공유와 보존 정책을 아는 소비 앱에서 정리하세요. 만료되는 서명 URL은 원본의 영구 참조로 적합하지 않습니다.

## Markdown 변환

`exportDocumentToMarkdown`은 문서와 변환 경고를 반환합니다. Markdown은 원본을 완전히 보존하는 백업 형식이 아닙니다.

| 요소 | 결과 |
|---|---|
| 기본 문단·제목·인용·목록·서식 | 대응 Markdown 문법 |
| 체크리스트·취소선 | GFM 문법 |
| 코드 블록 | 코드 안의 백틱보다 긴 fence |
| 이미지 | alt와 URL을 가진 이미지 문법 |
| 사진 캡션 | 별도 문단, `CAPTION_AS_PARAGRAPH` 경고 |
| 2열 | 왼쪽 다음 오른쪽의 세로 본문, `COLUMNS_FLATTENED` 경고 |

경고는 종류별로 한 번만 반환합니다. 편집 가능한 원본을 보존하려면 JSON을 저장하세요. v1에서는 Markdown 파일 가져오기와 다른 에디터 JSON의 직접 변환을 지원하지 않습니다.
